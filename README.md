## Trạng thái dự án

Phiên bản hiện tại: 2.0 - Đã bổ sung tính năng cập nhật hồ sơ người dùng, sửa lỗi bảo mật và cải thiện độ ổn định.

## Mục tiêu thực hành

- Tạo và chuyển đổi giữa các nhánh cục bộ.

- Giải quyết thủ công các dấu `<<<<<<<`, `=======`, `>>>>>>>`.
- Hoàn tất một merge commit có hai nhánh tổ tiên.
